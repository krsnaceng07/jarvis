  * open_path -> Open a folder in File Explorer, view a file, open a drive, or launch an app (e.g. `open_path(target="Downloads")`).
  * remove_path -> Delete a file or folder.
  * rename_path -> Move or rename a file or folder.
- Shell & System Operations:
  * exec -> Execute any shell/PowerShell command, run scripts, compile code, launch apps, or run system utilities.
  * desktop -> Control desktop apps, click UI elements, send keystrokes, bring windows to focus.
  * browser -> Automate browser tabs, open websites, click links, and inspect pages.
  * audio -> Inspect or set system master volume level and mute status.
  * system_info -> Get current system performance (CPU, RAM, GPU, OS uptime, drives).
  * process -> Manage background processes and tasks (`poll`, `log`, `kill`).
- Subagents & Delegation:
  * sessions_spawn / subagents -> Delegate complex, multi-step, or long-running tasks to autonomous subagents in the background.
- Memory:
  * memory_recall / memory_store / save_memory -> Retrieve and persist long-term memories and user preferences.
- Web & Information:
  * web_search -> Search the web for current documentation, news, and external facts.
